# playwright-agent-kit

Agent-first Playwright POM framework. Fork this repo to start your own test automation project.

## Getting started

```bash
npm run setup
npm test
```

## Structure

- `pages/` — Page Object Model base classes
- `.claude/` — Claude Code skills and agents
